Status

Completed

Project Overview

Aplikasi ini adalah platform booking paket wisata berbasis Laravel yang terintegrasi dengan Midtrans untuk pembayaran online. Pengguna bisa mencari destinasi, melihat detail paket, memesan paket wisata, checkout, dan mengunduh invoice PDF. Admin dapat mengelola paket wisata, memverifikasi pesanan, serta menangani pembatalan dan promosi.

Features

Fitur Pengguna (Umum)

  • Halaman utama dengan daftar destinasi dan pencarian paket wisata
  • Halaman informasi destinasi terperinci
  • Sistem pemesanan paket wisata dengan detail penumpang
  • Integrasi proses pembayaran online dan checkout menggunakan Midtrans
  • Panggilan balik konfirmasi pembayaran otomatis dari Midtrans
  • Manajemen pesanan dan permintaan pembatalan pemesanan
  • Unduh faktur dalam format PDF
  • Halaman bantuan dan dukungan
  • Dukungan multibahasa (Indonesia & Inggris)

Fitur Admin

  • Autentikasi admin (Login & Logout)
  • Manajemen admin untuk Super Admin (CRUD Admin)
  • Kelola banner, logo, dan promosi di halaman beranda
  • Manajemen CRUD untuk paket wisata
  • Verifikasi pemesanan dan validasi pembayaran
  • Ekspor laporan pemesanan ke PDF
  • Sistem persetujuan pembatalan pemesanan
