Project Overview

Aplikasi web manajemen asrama ini dibangun menggunakan PHP untuk backend, database SQL (kemungkinan MySQL) untuk penyimpanan data, dan HTML/CSS untuk antarmuka pengguna. Sistem ini menyediakan fitur booking kamar, manajemen siswa dan admin, pembayaran, serta laporan, dengan struktur folder terorganisir untuk admin, API, dan aset publik. Aplikasi ini dirancang untuk memfasilitasi pengelolaan asrama secara efisien melalui panel admin dan akses pengguna.

Features

Fitur Pengguna (Umum)

  • Beranda: Tampilan utama dengan daftar kamar terbaru (maksimal 3 kamar) dan navigasi ke halaman lain
  • Katalog Kamar: Daftar lengkap kamar dengan filter berdasarkan status (Tersedia/Ditempati) dan gedung (Gedung 1/Gedung 2)
  • Kontak Kami: Halaman informasi kontak asrama
  • Booking Kamar: Formulir booking dengan input data siswa (nama, NIS, nomor WA, asal sekolah, jurusan), pemilihan kamar, tanggal booking, durasi, dan upload bukti pembayaran (gambar JPG/PNG)

Fitur Admin

  • Dashboard: Ringkasan statistik (booking pending, kamar kosong, total siswa aktif) dan sambutan berdasarkan waktu
  • Data Siswa: Manajemen data siswa (tambah, edit, hapus, lihat status akun)
  • Manajemen Kamar: Kelola kamar (tambah, edit, hapus, lihat status dan detail)
  • Booking: Kelola permintaan booking (lihat, proses, konfirmasi status)
  • Pembayaran: Kelola pembayaran (lihat bukti, konfirmasi pembayaran)
  • Laporan: Laporan aktivitas asrama (kemungkinan ringkasan booking, pembayaran, dll.)
  • Login/Register: Akses login admin, register admin baru, dan edit password
  • Logout: Keluar dari sistem admin
