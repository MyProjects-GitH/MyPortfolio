Project Overview

Proyek ini adalah situs web informatif yang menampilkan berita, galeri, dokumen, dan video. Struktur dibuat dengan HTML, tampilan dirancang menggunakan CSS, dan interaksi sederhana ditangani dengan JavaScript.

Features

Fitur

  • Navigasi halaman dengan menu utama: Beranda, AD / ART, Galeri, Dokumen
  • Halaman galeri dan video
  • Halaman dokumen untuk kumpulan materi
  • Desain responsif
  • Integrasi ikon sosial media dengan Font Awesome
